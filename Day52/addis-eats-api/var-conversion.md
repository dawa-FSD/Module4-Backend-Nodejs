# Exercise 3 - Convert var to const or let

Use five `var` declarations from one of your own Module 2 files. The examples below show the expected format; replace or adapt them to match your real code.

## Before and after

1. Before: `var restaurantName = "Addis Eats";`
   After: `const restaurantName = "Addis Eats";`
   Reason: The variable is not reassigned.

2. Before: `var quantity = 1;`
   After: `let quantity = 1;`
   Reason: The quantity changes when the customer adds another item.

3. Before: `var isOpen = true;`
   After: `const isOpen = true;`
   Reason: The value is not reassigned.

4. Before: `var total = 0;`
   After: `let total = 0;`
   Reason: The total is updated while calculating an order.

5. Before: `var customerName = "Dawa";`
   After: `const customerName = "Dawa";`
   Reason: The name is not reassigned in this example.
